# Harry Potter Characters

Практическая работа №3 (pr3).
Веб-приложение для просмотра и фильтрации персонажей вселенной Harry Potter.

## Стек технологий
- Vite
- React + TypeScript
- Oxlint
- Вёрстка: CSS Flexbox и CSS Grid (адаптивная)
- Данные: HP-API

## Запуск проекта

```bash
npm install
npm run dev
npm run lint
npm run build
```
